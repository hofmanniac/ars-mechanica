## Overview

This combination creates a dual-layer economy where players manage both action points (what you can do) and resources (what you have). The two systems interweave — actions cost points and produce resources, while resources can be spent for better actions or converted back into action points. This creates complex optimization puzzles where players must balance both currencies effectively.

## How It Works

**Dual Economy Structure**:

**Action Points (AP)**: What you can do this turn
- Limited per turn (typically 3-5 points)
- Spent to take actions
- Usually reset each turn (don't carry over)

**Resources**: What you have accumulated
- Persist between turns
- Produced by spending action points
- Spent on various game actions or goals

**Interaction Patterns**:

**AP → Resources**
- "Spend 1 AP: Gain 2 wood"
- Action points harvest resources
- Foundational pattern

**Resources → AP**
- "Spend 3 gold: Gain 2 bonus actions"
- Resources buy extra actions
- Creates acceleration potential

**Combined Costs**
- "Spend 2 AP + 3 wood: Build house"
- Actions require both currencies
- Dual optimization puzzle

**Resource-Efficient Actions**
- "Spend 1 AP + 1 gold: Gain 5 wood"
- Resources make actions more efficient
- Rewards resource investment

**AP-Efficient Actions**
- "Spend 2 gold: Gain 3 wood (no AP cost)"
- Resources substitute for actions
- Action economy upgrade

## Why It Works

This combination creates sophisticated strategic depth:

**Multi-Dimensional Optimization**
- Must optimize both action economy AND resource economy
- Two layers of scarcity to manage
- Creates rich decision space

**Temporal Strategy**
- Action points operate on turn timescale (immediate)
- Resources operate on multi-turn timescale (persistent)
- Bridges tactical and strategic thinking

**Resource Conversion Puzzle**
- Converting between the two currencies
- Finding efficient conversion paths
- Timing conversions optimally

**Escalating Complexity**
- Early game: Simple AP → Resource generation
- Mid game: Resource stockpiles enable better actions
- Late game: Complex AP/Resource combinations

**Anti-Stagnation**
- Resources alone can't win (need actions to use them)
- Actions alone can't win (need resources to progress)
- Forces balanced play

## Design Considerations

### Economy Balance

**How should AP and Resources relate?**

**AP as Gatekeeper**
- Actions always cost AP (primary limiter)
- Resources supplement actions (secondary concern)
- AP is the tight constraint

**Resources as Gatekeeper**
- Actions cost few/no AP if you have resources
- Resources are primary limiter
- Resource accumulation is the game

**Balanced Scarcity**
- Both matter equally
- Players constantly juggle both
- Sweet spot for complexity

### Conversion Rates

**Can AP convert to Resources and vice versa?**

**One-Way Conversion** (AP → Resources only)
- Simpler, more intuitive
- Resources accumulate naturally
- Resources as score or permanent progress

**Two-Way Conversion** (AP ↔ Resources)
- More complex optimization
- Dynamic economy
- Advanced strategy space

**Asymmetric Rates**
- AP → Resources efficient (1 AP = 3 resources)
- Resources → AP expensive (5 resources = 1 AP)
- Encourages planning ahead (save resources to buy AP later)

### Action Point Refresh

**How do players get AP each turn?**

**Fixed Refresh**
- Everyone gets same amount each turn
- Predictable, balanced
- Simple

**Resource-Based Refresh**
- Spend resources to determine AP for turn
- Resources control action economy
- High integration

**Variable Refresh**
- AP varies based on game state/investments
- Engine building element
- Complex but rewarding

### Resource Persistence

**Do resources carry over between turns?**

**Full Persistence**
- Keep all resources turn to turn
- Enables long-term planning
- Can lead to hoarding

**Partial Decay**
- Lose some resources each turn
- Use-it-or-lose-it pressure
- Encourages spending

**No Persistence** (rare)
- Must spend resources same turn gained
- Extreme pressure
- Simplifies but limits strategy

### Cost Structures

**How should actions be priced?**

**AP Only Costs**
- "2 AP: Build house"
- Simple, straightforward
- Resources used for other purposes

**Resource Only Costs**
- "5 wood: Build house"
- Action points just determine how many things you do
- Emphasis on resource generation

**Combined Costs**
- "1 AP + 3 wood: Build house"
- Both currencies matter
- Most interesting strategically

**Variable Costs**
- "2-4 AP: Gain wood (more AP = more wood)"
- Player choice in efficiency
- Flexible optimization

### Action Efficiency Scaling

**Do resources make actions better?**

**No Scaling**
- Resources don't improve actions
- Separate economies
- Simpler but less integrated

**Linear Scaling**
- "Spend resources to improve action output"
- 1 gold = +1 wood from harvest
- Predictable, mathematical

**Threshold Scaling**
- "Spend 3 resources: Action produces double"
- All-or-nothing boosts
- Creates clear breakpoints

**Multiplicative Scaling**
- "Resources multiply action effectiveness"
- Can scale dramatically
- Risk of imbalance

## Strategic Layers

**Economy Prioritization**
- Focus on action efficiency first?
- Or build resource stockpile?
- Which bottleneck matters more?

**Conversion Timing**
- When to convert resources to extra actions?
- When to hoard resources for later?
- Recognizing optimal conversion moments

**Action Sequencing**
- Order actions to maximize efficiency
- Generate resources early to use later in turn?
- Or use stored resources to boost early actions?

**Investment Payoff Analysis**
- Is it worth spending resources for extra AP?
- Break-even calculations
- Multi-turn planning

**Flexibility vs. Efficiency**
- Keep resources flexible (can use many ways)
- Or commit to efficient path (lock into strategy)
- Risk management

## Common Pitfalls

**Dominant Currency**: If one currency matters much more than the other, the dual economy collapses. Balance scarcity and utility of both.

**Conversion Loops**: If players can convert AP → Resources → AP profitably, infinite loops break the game. Ensure lossy conversions or limits.

**Analysis Paralysis**: Two currencies + many actions = complex optimization. Keep action space manageable or provide clear strategic frameworks.

**Resource Hoarding Dominance**: If hoarding resources to buy AP is always correct, tactics disappear. Make immediate action spending valuable.

**AP Starvation**: If players can be completely starved of AP, game becomes frustrating. Guarantee minimum viable actions per turn.

**Bookkeeping Overhead**: Tracking both currencies can be fiddly. Use good player aids, trackers, or tokens.

**Obvious Optimal Paths**: If same action sequence is always correct, decisions become rote. Create situational value and varied board states.

## Examples in Games

**Gloomhaven**: Cards provide action points (top/bottom actions) and determine initiative. Resources (loot, gold, XP) persist and enable character upgrades that provide better cards (more/better actions).

**Robinson Crusoe**: Action points determine how many actions you take, but many actions cost resources (wood, hides, food). Must balance gathering resources with spending them for survival.

**Mage Knight**: Action points (cards in hand) used to move, fight, and explore. Resources (mana, units) make actions more powerful or efficient. Complex action/resource optimization.

**Twilight Imperium**: Command tokens (limited action points) spent to activate systems. Resources (produced from planets) build fleets and structures. Strategic/tactical balance.

**Terraforming Mars**: Each turn you get 1-2 actions, but many actions cost resources (money, steel, titanium). Must generate resources through cards/production to afford big actions.

**Tzolk'in**: Place workers (action points) on gear wheels. As gears rotate, workers' positions improve, gaining more resources when retrieved. Time and resources interconnected uniquely.
